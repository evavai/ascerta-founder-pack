# Ascerta Founder Pack

Skills for founders, for agent workspaces that run on QM.

| Skill | What it does |
|---|---|
| `investor-update` | Drafts the periodic update from real numbers and last month's commitments — and holds it for approval |
| `runway-watch` | Keeps cash, burn and runway current; speaks up only when the number moves materially |
| `board-prep` | Assembles the board pack and surfaces the hard questions before the board asks them |
| `competitor-watch` | Watches a competitor's public surfaces and reports only what matters |
| `investor-center` | Matches the company to funders — VCs, angels, grants, accelerators — from a curated list you maintain in `funders.md` |
| `fundraise-pipeline` | Runs the raise as a pipeline — who is engaged, who has gone quiet, what we owe each one |

## Install

Add this repository as a skill pack in your workspace. Skills are plain markdown — read them before
you install them.

## Principles

These four share a handful of rules, and the rules are the point:

- **Nothing goes outbound on its own.** Draft, then stop and ask.
- **Never invent a number.** A figure that could not be pulled is named as missing, never estimated.
- **Stay quiet when nothing changed.** A watch that reports "no change" every week gets muted, and
  is then worth nothing on the week that matters.
- **Report, do not reassure.** The founder knows their position. The judgement is theirs.
